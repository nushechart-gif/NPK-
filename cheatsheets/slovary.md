# 📘 Шпаргалка: словари в Python (`dict`)

> **Словарь** — это коллекция пар `ключ : значение`.
> Аналогия: **телефонная книга**. Ты ищешь не «по порядку», а **по имени** (ключ), чтобы получить **номер** (значение).

---

## 1. Синтаксис

```python
# пустой словарь
d = {}
d = dict()

# сразу с данными
hero = {
    "name": "Артур",     # ключ : значение
    "health": 100,
    "mana": 50,
}
```

- Словарь живёт в **фигурных скобках** `{ }`
- **Ключ** слева от `:`, **значение** справа
- Пары разделены запятыми

### Другие способы создать

```python
hero = dict(name="Артур", health=100)          # ключи без кавычек
hero = dict([("name", "Артур"), ("health", 100)])  # из списка пар
hero = dict.fromkeys(["Артур", "Гвен"], 100)   # всем ключам одно значение
# {'Артур': 100, 'Гвен': 100}
```

---

## 2. Два железных правила

| Правило | Что значит |
|---|---|
| **Ключи уникальны** | Двух одинаковых ключей быть не может. Новый перезапишет старый. |
| **Ключ — неизменяемый (хэшируемый)** | Можно: строка, число, `True/False`, `None`, кортеж. Нельзя: список, другой словарь, множество. |

> Значения могут быть **любыми** и повторяться сколько угодно.

---

## 3. Чтение данных

```python
hero = {"name": "Артур", "health": 100}
```

| Как | Если ключ есть | Если ключа нет |
|---|---|---|
| `hero["health"]` | `100` | 💥 `KeyError` |
| `hero.get("health")` | `100` | `None` |
| `hero.get("mana", 50)` | `100` | `50` ← запасное значение |

**Правило выбора:** ключ точно есть → `[]`. Может не быть → `.get()`.

---

## 4. Добавление и изменение

```python
hero["strength"] = 10        # ключа не было → добавилось
hero["health"] = 80          # ключ был → значение заменилось

hero.update({"mana": 50, "strength": 10})   # много сразу
hero.update(mana=70)                          # ключи-слова
```

> ⚠️ `update()` возвращает `None`. Никогда не пиши `hero = hero.update(...)`.

---

## 5. Удаление

```python
del hero["mana"]              # просто удалил
mana = hero.pop("mana")       # удалил и ОТДАЛ значение
mana = hero.pop("mana", 0)    # то же, но без ошибки, если ключа нет
last = hero.popitem()         # удалил ПОСЛЕДНЮЮ пару → вернул (ключ, значение)
hero.clear()                  # удалил всё → {}
```

| Что нужно | Используй |
|---|---|
| Удалить и выбросить | `del d[k]` |
| Удалить и **использовать** значение | `d.pop(k)` |
| Очистить полностью | `d.clear()` |

---

## 6. Перебор

```python
hero = {"name": "Артур", "health": 100, "mana": 50}

for key in hero:                    # ключи (то же, что hero.keys())
    print(key)

for value in hero.values():         # значения
    print(value)

for key, value in hero.items():     # и то и другое ⭐
    print(key, "=", value)

if "name" in hero:                  # проверка НАЛИЧИЯ КЛЮЧА
    print("есть")
```

> ❗ `in` ищет **среди ключей**, а не среди значений.
> `"Артур" in hero` → `False`.

---

## 7. Все методы — одна таблица

| Метод | Что делает | Возвращает |
|---|---|---|
| ⭐ `get(k[, d])` | Читает; если ключа нет — `d` (или `None`) | значение |
| `setdefault(k[, d])` | Читает; если ключа **нет** — **создаёт** с `d` | значение |
| ⭐ `update(...)` | Добавляет/заменяет много пар сразу | `None` |
| ⭐ `pop(k[, d])` | Удаляет ключ и отдаёт значение | значение |
| `popitem()` | Удаляет последнюю пару | `(ключ, значение)` |
| `clear()` | Удаляет всё содержимое | `None` |
| ⭐ `keys()` | Все ключи | «живое окно» |
| `values()` | Все значения | «живое окно» |
| ⭐ `items()` | Все пары | «живое окно» |
| `copy()` | Поверхностная копия | новый словарь |
| `dict.fromkeys(seq[, v])` | Создаёт словарь из списка ключей | новый словарь |

**Не методы, но нужны каждый день:**

| Что | Значение |
|---|---|
| `len(hero)` | сколько пар |
| `k in hero` | есть ли **ключ** |
| `del hero[k]` | удалить по ключу |
| `a \| b` | склеить словари (правый побеждает при конфликте), Python 3.9+ |
| `a \|= b` | то же, но обновить `a` на месте |

> ❌ Методов `add()`, `append()`, `insert()` у словаря **нет**. Добавляют через `d[k] = v` или `update()`.

## 8. Словарь vs Список

| | Список `[]` | Словарь `{}` |
|---|---|---|
| По чему достаем | по **номеру** (`0, 1, 2`) | по **имени-ключу** |
| Порядок | важен | не важен (но сохраняется) |
| Дубликаты | можно | ключи — нельзя |
| Когда брать | ряд однородных вещей | данные с подписями |

```python
players = ["Артур", "Гвен"]              # список: порядок
stats   = {"Артур": 100, "Гвен": 80}     # словарь: имя → значение
```

## 9. Подводные камни ⚠️

### 1. `KeyError`
```python
hero["mana"]          # 💥 если ключа нет
hero.get("mana", 0)   # ✅
```

### 2. `update()` и `clear()` возвращают `None`
```python
hero = hero.update({"mana": 5})   # ❌ hero теперь None
hero.update({"mana": 5})          # ✅
```

### 3. `copy()` — копия только верхнего слоя
```python
hero   = {"name": "Артур", "inv": ["меч"]}
backup = hero.copy()
backup["inv"].append("щит")

print(hero["inv"])   # ['меч', 'щит'] ← оригиналу тоже досталось!
```
Для полной копии: `import copy` → `copy.deepcopy(hero)`.

### 4. `fromkeys` с мутируемым значением — ловушка
```python
heroes = dict.fromkeys(["Артур", "Гвен"], [])
heroes["Артур"].append("меч")

print(heroes["Гвен"])   # ['меч'] ← список ОДИН на двоих!
```
Правильно:
```python
heroes = {name: [] for name in ["Артур", "Гвен"]}
```

### 5. `keys()/values()/items()` — это не списки, а «живые окна»
```python
keys = hero.keys()
hero["mana"] = 50
print(keys)     # обновилось само — это трансляция, не фото
```
Нужен именно список → `list(hero.keys())`.

### 6. `popitem()` на пустом словаре → ошибка
```python
{}.popitem()   # 💥 KeyError
```

## 10. Готовые рецепты 🧪

```python
# Подсчёт
counts = {}
for w in "banana":
    counts[w] = counts.get(w, 0) + 1        # {'b':1,'a':3,'n':2}

# Сумма всех значений
total = sum(hero.values())

# Безопасный доступ к вложенному
hp = hero.get("stats", {}).get("hp", 0)

# Сортировка по значению (от большего)
best = sorted(hero.items(), key=lambda kv: kv[1], reverse=True)

# Поменять ключи и значения местами
inv = {v: k for k, v in hero.items()}

# Преобразовать значения
doubled = {k: v * 2 for k, v in hero.items() if isinstance(v, int)}

# Слить два словаря (не трогая оригиналы)
merged = {**hero, "extra": 1}
merged = hero | {"extra": 1}

# Пустой ли словарь?
if not hero:
    print("пусто")

# Первый ключ / первое значение
first_key = next(iter(hero))
```

## 11. Если запомнить только четыре вещи

1. **`d[k]`** — читаю, когда уверен, что ключ есть.
2. **`d.get(k, default)`** — читаю, когда ключа может не быть.
3. **`for k, v in d.items()`** — перебираю весь словарь.
4. **`d.pop(k)`** — удаляю и забираю значение.

Остальное — по необходимости. Никто не держит это в голове, все подглядывают. 🙃
