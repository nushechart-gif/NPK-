# 📐 Шпаргалка: Табуляция и отступы

## 🎯 Главное правило

**Двоеточие `:` в конце строки = следующая строка с отступом.**

Если после слова стоит двоеточие (`if`, `while`, `for`, `def`, `else`, `elif`) — всё, что относится к этому блоку, **должно быть с отступом**.

---

## ✅ Где ставить отступ (4 пробела)

### После `if / elif / else`:

```python
if health > 0:
    print("Герой жив")     # ← отступ
После циклов while / for:
while health > 0:
    health = health - 1    # ← отступ
    
for i in range(5):
    print(i)               # ← отступ
После def (внутри функции):
def hello():
    print("Привет!")       # ← отступ
Вложенные блоки (отступ внутри отступа):
if health > 0:
    if gold > 10:
        print("Купил меч") # ← двойной отступ (8 пробелов)
❌ Где НЕ ставить отступ
После блока закончился:
if health > 0:
    print("Жив")           # отступ
print("Конец проверки")    # ← БЕЗ отступа! Блок закончился
if health > 0:
    print("Раз")           # отступ
    print("Два")           # тот же отступ
    print("Три")           # тот же отступ
