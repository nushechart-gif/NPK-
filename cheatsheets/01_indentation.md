# 📐 Шпаргалка: Табуляция и отступы

## 🎯 Главное правило

**Двоеточие `:` в конце строки = следующая строка с отступом.**

Если после слова стоит двоеточие (`if`, `while`, `for`, `def`, `else`, `elif`) — всё, что относится к этому блоку, **должно быть с отступом**.

---

## ✅ Где ставить отступ (4 пробела)

### После `if / elif / else`:

```python
if health > 0:
    print("Герой жив")     # ← отступ
```

### После циклов `while / for`:

```python
while health > 0:
    health = health - 1    # ← отступ
    
for i in range(5):
    print(i)               # ← отступ
```

### После `def` (внутри функции):

```python
def hello():
    print("Привет!")       # ← отступ
```

### Вложенные блоки (отступ внутри отступа):

```python
if health > 0:
    if gold > 10:
        print("Купил меч") # ← двойной отступ (8 пробелов)
```

---

## ❌ Где НЕ ставить отступ

### После блока закончился:

```python
if health > 0:
    print("Жив")           # отступ
print("Конец проверки")    # ← БЕЗ отступа! Блок закончился
```

### Строки на одном уровне:

```python
if health > 0:
    print("Раз")           # отступ
    print("Два")           # тот же отступ
    print("Три")           # тот же отступ
```

---

## ⚠️ Частые ошибки

| Ошибка | Что будет | Как исправить |
|--------|-----------|---------------|
| Забыл отступ после `:` | `IndentationError` | Поставь 4 пробела |
| Лишний отступ там, где блок закончился | `IndentationError` | Убери отступ (Backspace) |
| Разный уровень отступа в одном блоке | `IndentationError` | Выровняй по одной линии |
| Смешал табы и пробелы | `TabError` | Настрой редактор (см. ниже) |

## 🔧 Настройка VS Code

Чтобы табуляция всегда была правильной:

1. Открой **Файл → Настройки → Параметры** (или `Ctrl + ,`)
2. Найди **"Indent"** в поиске
3. Поставь:
   - **Tab Size: 4**
   - **Insert Spaces: ✅** (включено)
   - **Detect Indentation: ✅**

Теперь при нажатии `Tab` редактор будет вставлять **4 пробела**, а не символ таба. Это спасёт от `TabError`.

---

## 🎮 Горячие клавиши в VS Code

| Клавиша | Что делает |
|---------|-----------|
| `Tab` | Сдвинуть строку вправо (отступ) |
| `Shift + Tab` | Сдвинуть строку влево (убрать отступ) |
| `Ctrl + ]` | То же, что `Tab` |
| `Ctrl + [` | То же, что `Shift + Tab` |

**Лайфхак:** Выдели несколько строк мышкой и нажми `Tab` — они все сдвинутся вместе. Это удобно, когда надо выровнять целый блок.

## 📋 Правило «коробок»

Представь, что каждый блок кода — это **коробка**:

```
┌─ if (большая коробка) ────────────┐
│                                    │
│  ┌─ while (коробка внутри) ─────┐ │
│  │                               │ │
│  │   ┌─ if (ещё меньше) ──────┐ │ │
│  │   │                         │ │ │
│  │   │   код                   │ │ │
│  │   │                         │ │ │
│  │   └─────────────────────────┘ │ │
│  │                               │ │
│  └───────────────────────────────┘ │
│                                    │
└────────────────────────────────────┘
```

Каждый уровень вложенности = ещё одна коробка внутри. Отступ показывает, в какой коробке ты сейчас находишься.

## ✅ Чек-лист перед запуском кода

- [ ] После каждого `:` следующая строка с отступом
- [ ] Все строки одного блока на одном уровне
- [ ] Когда блок закончился — отступ убран
- [ ] Вложенные блоки имеют больше отступов
- [ ] Нет смешения табов и пробелов
