# 📝 Шпаргалка: F-строки (f-strings)

## 🎯 Что такое f-строки

F-строки — это способ **встраивать переменные прямо внутрь текста**. 
Чтобы её создать, нужно поставить букву `f` перед открывающей кавычкой.

### Без f-строки (старый, неудобный способ):
```python
name = "Артур"
health = 100
print("Герой", name, "имеет здоровье", health)
# Минусы: много кавычек, запятых, легко запутаться
```

### С f-строкой (правильный способ):
```python
name = "Артур"
health = 100
print(f"Герой {name} имеет здоровье {health}")
# Результат: Герой Артур имеет здоровье 100
```

⚠️ **Главное правило:** Буква `f` должна стоять ПЕРЕД кавычками (`f"..."`), а переменные оборачиваются в фигурные скобки `{}`.

---

## 🧩 Что можно писать внутри фигурных скобок `{}`

### 1. Переменные
```python
gold = 50
print(f"У тебя {gold} монет.")
```

### 2. Математические выражения
Питон сам посчитает результат до того, как вставит его в строку.
```python
apples = 5
eaten = 2
print(f"Осталось яблок: {apples - eaten}")   # Осталось яблок: 3
print(f"Всего было: {apples * 2}")           # Всего было: 10
```

### 3. Вызов методов строк
```python
name = "артур"
print(f"Имя с большой буквы: {name.capitalize()}")
# Имя с большой буквы: Артур
```

### 4. Вызов функций
```python
inventory = ["меч", "зелье"]
print(f"Предметов в рюкзаке: {len(inventory)}")
# Предметов в рюкзаке: 2
```

---

## ⚔️ Применение в текстовом квесте

F-строки идеально подходят для вывода статусов героя:

```python
name = "Артур"
hp = 75
max_hp = 100
weapon = "Железный меч"
is_poisoned = False

# Красивый вывод статуса
print(f"=== СТАТУС ГЕРОЯ ===")
print(f"Имя: {name}")
print(f"Здоровье: {hp}/{max_hp}")
print(f"Оружие: {weapon}")
print(f"Отравлен: {'Да' if is_poisoned else 'Нет'}")
```

## 🚨 Частые ошибки

| Ошибка | Код | Как исправить |
|--------|-----|---------------|
| Забыл букву `f` | `"{name} привет"` | `f"{name} привет"` |
| Написал `F` вместо `f` | Работает, но не принято | Пиши маленькую `f` |
| Поставил `f` после кавычки | `"f{name}"` | `f"{name}"` |
| Использовал одинаковые кавычки внутри | `f"Он сказал "Привет""` | `f'Он сказал "Привет"'` |
| Обратный слэш внутри `{}` | `f"Путь: {C:\new}"` | Сохрани путь в переменную до f-строки |

## 💡 Лайфхаки

### 1. Если нужны фигурные скобки в тексте
Если тебе нужно вывести сами символы `{` или `}`, удвой их:
```python
print(f"Словари создаются так: {{'ключ': 'значение'}}")
# Вывод: Словари создаются так: {'ключ': 'значение'}
```

### 2. Округление дробных чисел
Если у тебя есть число с плавающей точкой (например, урон 15.66666), можно указать, сколько знаков оставить после запятой:
```python
damage = 15.66666
print(f"Нанесено урона: {damage:.2f}")
# Вывод: Нанесено урона: 15.67
```

### 3. Многострочные f-строки
Если текст длинный, используй тройные кавычки:
```python
name = "Артур"
hp = 100

status = f"""
Ты заходишь в таверну.
Бармен смотрит на тебя:
'Привет, {name}! Вижу, ты здоров, раз у тебя {hp} HP.'
"""
print(status)
```

## ✅ Чек-лист перед запуском

- [ ] Перед кавычками стоит буква `f` (или `F`)
- [ ] Переменные внутри текста обёрнуты в `{}`
- [ ] Нет синтаксических ошибок внутри `{}`
- [ ] Если внутри нужны кавычки, они отличаются от внешних (внешние `"`, внутренние `'`)
