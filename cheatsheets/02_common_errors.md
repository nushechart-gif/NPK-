# 🚨 Шпаргалка: Частые ошибки и как их исправить

## 1. `IndentationError: expected an indented block`

**Что значит:** После `:` ты забыл поставить отступ.

**Было:**
```python
if health > 0:
print("Жив")   # ❌ нет отступа
```

**Стало:**
```python
if health > 0:
    print("Жив")   # ✅ отступ
```

---

## 2. `IndentationError: unindent does not match`

**Что значит:** Строки в одном блоке имеют разный отступ.

**Было:**
```python
if health > 0:
    print("Жив")
  print("Проверка")   # ❌ другой отступ
```

**Стало:**
```python
if health > 0:
    print("Жив")
    print("Проверка")   # ✅ тот же отступ
```

---

## 3. `TabError: inconsistent use of tabs and spaces`

**Что значит:** В одном файле смешаны табы и пробелы.

**Как исправить:**
1. Выдели весь код (`Ctrl + A`)
2. Нажми `Shift + Tab` (убрать все отступы)
3. Снова расставь отступы правильно (`Tab`)
4. Убедись, что в настройках включён **Insert Spaces**

---

## 4. `SyntaxError: invalid syntax`

**Что значит:** Где-то пропущено двоеточие, скобка или кавычка.

**Проверь:**
- [ ] Двоеточие после `if`, `while`, `for`, `def`, `else`, `elif`
- [ ] Скобки закрыты: `(` ... `)`
- [ ] Кавычки парные: `"..."` или `'...'`

---

## 5. `NameError: name 'xxx' is not defined`

**Что значит:** Переменная не создана или опечатка в имени.

**Было:**
```python
health = 100
print(helth)   # ❌ опечатка
```

**Стало:**
```python
health = 100
print(health)   # ✅
```

---

## 6. `TypeError: unsupported operand type(s)`

**Что значит:** Пытаешься сложить/вычесть разные типы (например, текст и число).

**Было:**
```python
age = input("Сколько лет? ")
print(age + 1)   # ❌ age — это текст!
```

**Стало:**
```python
age = int(input("Сколько лет? "))
print(age + 1)   # ✅ превратили в число
```

---

## 7. Бесконечный цикл (программа «зависла»)

**Что значит:** В цикле `while` не меняется условие, и он крутится вечно.

**Было:**
```python
health = 100
while health > 0:
    print("Игра идёт")   # ❌ health не меняется!
```

**Стало:**
```python
health = 100
while health > 0:
    print("Игра идёт")
    health = health - 1   # ✅ health уменьшается, цикл закончится
```

---

## 8. `print` и `return` перепутаны

**Что значит:** Функция печатает, но не возвращает значение.

**Было:**
```python
def add(a, b):
    print(a + b)   # ❌ показывает, но не отдаёт

result = add(3, 5)
print(result)      # ❌ напечатает None
```

**Стало:**
```python
def add(a, b):
    return a + b   # ✅ отдаёт значение

result = add(3, 5)
print(result)      # ✅ напечатает 8
```

---

## 9. Функция создана, но не вызвана

**Что значит:** Написал `def`, но забыл вызвать функцию.

**Было:**
```python
def hello():
    print("Привет!")

# ❌ ничего не произойдёт
```

**Стало:**
```python
def hello():
    print("Привет!")

hello()   # ✅ вызвали — теперь сработает
```

---

## 10. Вызов функции без скобок

**Что значит:** Написал имя функции, но без `()`.

**Было:**
```python
hello    # ❌ это не вызов, просто имя
```

**Стало:**
```python
hello()  # ✅ скобки обязательны
```

---

## 🔍 Как читать сообщение об ошибке

Когда видишь ошибку, смотри на **последнюю строку**:

```
  File "quest.py", line 15
    print("Жив")
        ^
IndentationError: expected an indented block
```

- **File "quest.py"** — в каком файле ошибка
- **line 15** — на какой строке
- **`^`** — где именно
- **Последняя строка** — что за ошибка

---

## ✅ Алгоритм поиска ошибки

1. Прочитай **последнюю строку** ошибки — там её тип
2. Посмотри на **номер строки** — перейди туда в коде
3. Проверь:
   - [ ] Двоеточие стоит?
   - [ ] Отступ правильный?
   - [ ] Скобки закрыты?
   - [ ] Кавычки парные?
   - [ ] Переменная создана?
4. Исправь и запусти снова
