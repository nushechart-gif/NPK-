# 📘 Шпаргалка по Markdown

**Markdown** — это язык разметки для оформления текста. Этот файл сам является примером: откройте его в Obsidian или VS Code, чтобы увидеть красивый результат.

---

## 📄 Создание файлов
- **VS Code**: `Ctrl+N` (новый файл) → `Ctrl+S` (сохранить как `name.md`) → `Ctrl+Shift+V` (предпросмотр).
- **Obsidian**: `Ctrl+N` (новая заметка). Слева — исходный код, справа — предпросмотр.

---

## # Заголовки
Используйте символ `#` с пробелом. Чем больше `#`, тем меньше заголовок.
# Заголовок 1 (H1)
## Заголовок 2 (H2)
### Заголовок 3 (H3)
#### Заголовок 4 (H4)

---

## ✏️ Форматирование текста
- **Жирный текст**: `**жирный**`
- *Курсив*: `*курсив*`
- ***Жирный курсив***: `***жирный курсив***`
- ~~Зачёркнутый~~: `~~зачёркнутый~~`
- `Код в строке`: `` `код` ``

---

## 📋 Списки
### Маркированный список
- Первый пункт
- Второй пункт
  - Подпункт (отступ 2 пробела)
- Третий пункт

### Нумерованный список
1. Первый шаг
2. Второй шаг
3. Третий шаг

## 💻 Блоки кода
Используйте три обратные кавычки и название языка:
```python
def hello():
    print("Привет, мир!")
    
hello()
```

---

## 🔗 Ссылки
Формат: `[Текст ссылки](URL)`  
Пример: [Официальная документация Python](https://docs.python.org/3/)

---

## 🖼️ Изображения
Формат: `![Описание](URL_картинки)`  
Пример:
![Логотип Python](https://www.python.org/static/community_logos/python-logo-master-v3-T.png)

> 💡 **Совет:** храните картинки в папке `images/` внутри вашего проекта.

---

## 📊 Таблицы
Используйте `|` для столбцов и `-` для разделения заголовка:

| Метод | Описание | Пример |
|---|---|---|
| `append()` | Добавить элемент | `lst.append(5)` |
| `remove()` | Удалить элемент | `lst.remove(3)` |
| `pop()` | Удалить по индексу | `lst.pop(0)` |
| `sort()` | Отсортировать список | `lst.sort()` |
