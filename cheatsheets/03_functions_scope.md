# 🧩 Шпаргалка: Функции и область видимости

## 📌 Что такое функция

Функция — это блок кода, который можно вызывать много раз по имени.

```python
def имя_функции(параметры):
    # тело функции
```

---

## 🎯 Синтаксис

### Создание и вызов

```python
def hello():
    print("Привет!")

hello()   # вызов — скобки обязательны!
```

⚠️ Без скобок (`hello`) функция НЕ запустится.

### Функция с параметром

```python
def greet(name):
    print("Привет,", name)

greet("Аня")
```

### Функция с return

```python
def add(a, b):
    return a + b

result = add(3, 5)   # result = 8
```

---

## ⚖️ print vs return

| | `print` | `return` |
|---|---|---|
| Что делает | Показывает на экране | Отдаёт значение программе |
| Можно сохранить в переменную? | ❌ Нет (вернёт None) | ✅ Да |

```python
def show(x):
    print(x)      # показывает, но возвращает None

def give(x):
    return x      # возвращает значение

a = show(10)   # a = None
b = give(10)   # b = 10
```

## 🌍 Область видимости

### Глобальные переменные
Созданы ВНЕ функции. Видны во всей программе.

```python
gold = 100   # глобальная
```

### Локальные переменные
Созданы ВНУТРИ функции. Видны только внутри неё.

```python
def foo():
    x = 10   # локальная
    print(x)

foo()
# print(x)  # ❌ ОШИБКА! Снаружи функция не существует
```

---

## 🚨 ГЛАВНАЯ ЛОВУШКА: «тихая ошибка»

```python
health = 100

def take_damage():
    health = 70   # ⚠️ Это ЛОКАЛЬНАЯ переменная!

take_damage()
print(health)     # ❌ Всё ещё 100! Глобальная не изменилась!
```

**Почему:** когда ты пишешь `health = 70` внутри функции, Питон создаёт **новую локальную** переменную. Глобальная остаётся нетронутой.

---

## ✅ ПРАВИЛЬНЫЙ СПОСОБ: параметры и return

```python
health = 100

def apply_damage(hp, damage):
    return hp - damage

health = apply_damage(health, 30)   # сохраняем результат обратно
print(health)   # ✅ 70
```

**Правило:** не меняй глобальные переменные внутри функции. Передай значение параметром, обработай, верни через `return`, сохрани обратно.

---

## 📋 Правило «коробок»

```
┌─ Глобальная область (вся программа) ──────┐
│                                            │
│  gold = 100  (видна везде)                 │
│                                            │
│  ┌─ Функция (коробка внутри) ───────────┐ │
│  │                                       │ │
│  │  hp = 50  (видна только тут)          │ │
│  │                                       │ │
│  └───────────────────────────────────────┘ │
│                                            │
└────────────────────────────────────────────┘
```

- Изнутри коробки можно **смотреть наружу** (читать глобальные).
- Снаружи **нельзя смотреть внутрь** (локальные не видны).

## ✅ Чек-лист перед запуском функции

- [ ] После `def имя(...)` стоит двоеточие
- [ ] Тело функции с отступом
- [ ] Скобки при вызове стоят: `hello()`, а не `hello`
- [ ] Если нужен результат — использую `return`, а не `print`
- [ ] Не меняю глобальные переменные внутри функции без необходимости
- [ ] Передаю данные параметрами, возвращаю через `return`
