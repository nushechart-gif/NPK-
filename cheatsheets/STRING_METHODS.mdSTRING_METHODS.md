# 📚 Шпаргалка: Все методы строк в Python

---

## 🔍 Поиск и проверка

| Метод | Что делает | Пример |
|-------|-----------|--------|
| `.find(что)` | Индекс первого вхождения (или -1) | `"кот".find("о")` → `1` |
| `.count(что)` | Сколько раз встречается | `"молоко".count("о")` → `3` |
| `in` | Есть ли подстрока? | `"о" in "кот"` → `True` |
| `.startswith(что)` | Начинается ли с...? | `"привет".startswith("при")` → `True` |
| `.endswith(что)` | Заканчивается ли на...? | `"файл.py".endswith(".py")` → `True` |

---

## ✅ Проверки (is-методы, возвращают True/False)

| Метод | Что проверяет |
|-------|---------------|
| `.isalpha()` | Только буквы |
| `.isdigit()` | Только цифры |
| `.isalnum()` | Буквы или цифры |
| `.isspace()` | Только пробелы |
| `.isupper()` | Все буквы заглавные |
| `.islower()` | Все буквы строчные |
| `.istitle()` | Каждое слово с большой буквы |

---

## ✏️ Изменение регистра и очистка

| Метод | Что делает |
|-------|-----------|
| `.lower()` | В нижний регистр |
| `.upper()` | В верхний регистр |
| `.capitalize()` | Первая буква заглавная |
| `.title()` | Каждое слово с заглавной |
| `.strip()` | Убирает пробелы по краям |
| `.lstrip()` / `.rstrip()` | Только слева / только справа |

---

## 🔄 Замена и разбиение

| Метод | Что делает | Пример |
|-------|-----------|--------|
| `.replace(что, на_что)` | Заменяет подстроку | `"кот".replace("о","а")` → `"кат"` |
| `.split(разделитель)` | Разбивает в список | `"а б в".split()` → `['а','б','в']` |
| `"-".join(список)` | Склеивает список в строку | `"-".join(['а','б'])` → `"а-б"` |

---

## 📏 Длина

| Функция | Что делает |
|---------|-----------|
| `len(строка)` | Количество символов |

---

## 💡 Быстрые примеры

```python
text = "  Привет, Мир!  "

# Очистка и регистр
text.strip()           # "Привет, Мир!"
text.lower()           # "  привет, мир!  "
text.upper()           # "  ПРИВЕТ, МИР!  "
text.title()           # "  Привет, Мир!  "

# Поиск
text.find("Мир")       # 10
text.count("и")        # 2
"Мир" in text          # True

# Проверки
"123".isdigit()        # True
"abc".isalpha()        # True
"abc123".isalnum()     # True

# Разбиение и склейка
"a,b,c".split(",")     # ['a', 'b', 'c']
"-".join(['a','b','c']) # "a-b-c"
