## 📚 О репозитории

Здесь лежат все материалы курса: примеры кода с лекций, шаблоны квестов и задания для практики. 

### 📥 Как скачать материалы
1. Нажми зелёную кнопку **Code** (вверху справа).
2. Выбери **Download ZIP**.
3. Распакуй архив на свой компьютер и открой папку в VS Code.
